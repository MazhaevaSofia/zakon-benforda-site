# Закон Бенфорда: сайт-инструмент

Сайт для проверки чисел на соответствие закону Бенфорда. Сделан для исследовательской работы по математике (автор: Мажаева).

Весь сайт находится в одном файле `index.html`. Ничего устанавливать не нужно.

## Как открыть на компьютере

Дважды щёлкните по `index.html`. Он откроется в браузере (Safari, Chrome, Firefox, Edge). Для шрифтов нужен интернет, без него сайт тоже работает, просто со стандартными шрифтами.

## Что есть на сайте

- **Инструмент.** Проверка своих чисел: вставить вручную, загрузить CSV или взять готовый пример. График, таблица, хи-квадрат, p-значение, MAD с подсказками к каждой цифре.
- **Подходят ли данные.** Короткий опросник перед анализом.
- **Слайдер размера выборки.** Показывает, почему мало чисел недостаточно.
- **Попробуй обмануть закон.** Проверка придуманных чисел.
- **Теория, Применение, Источники.** История закона, формулы, примеры использования, список литературы.
- **Игра.** Угадать, какой набор чисел настоящий.
- **История.** Проверки за текущую сессию с быстрым возвратом к результату.
- **Учителю.** Готовый план урока на 20 минут с вопросами для обсуждения.
- Ссылка «Поделиться результатом», печать и сохранение в PDF.
- Три языка (русский, беларуская, English), светлая и тёмная тема, увеличение текста для слабовидящих.

## Как выложить на GitHub Pages

1. Войдите на [github.com](https://github.com) (или зарегистрируйтесь, это бесплатно).
2. Нажмите **New** (или **+** в правом верхнем углу, потом **New repository**).
3. Впишите имя, например `zakon-benforda`, выберите **Public** и нажмите **Create repository**.
4. На странице репозитория нажмите **uploading an existing file** (или **Add file**, потом **Upload files**).
5. Перетащите в окно файлы `index.html` и `README.md` из этой папки и нажмите **Commit changes**.
6. Откройте **Settings**, слева выберите **Pages**.
7. В разделе **Build and deployment** в поле **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
8. Через одну-две минуты обновите страницу. Сверху появится ссылка вида `https://ваш-логин.github.io/zakon-benforda/`.

Эта ссылка открывается у любого человека без входа в аккаунт.

## Как поправить что-то после публикации

Откройте `index.html` на GitHub, нажмите на значок карандаша (**Edit**), внесите правку и нажмите **Commit changes**. Через минуту-две изменения появятся по той же ссылке.
